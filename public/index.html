A little clarity

Got questions?

A few things to know before you start building.

Talk to us ↗
What can I build with BJCRUM?+

Create full-stack web apps, websites, and client projects from a description. BJCRUM brings planning, a live preview, databases, authentication, and publishing into one workspace.

Can I keep improving my app?+

Yes. Return to your project to request changes and review them in the live preview. Version history lets you restore an earlier version when you need to.

How do plans and credits work?+

The free Solo plan includes 60 credits granted once, with no card required. Paid Solo and Agency plans include a monthly credit allowance. Select a plan inside BJCRUM; all listed prices are in USD.

Does BJCRUM test my app?+

The AI workflow includes browser testing to help identify issues. Review and test important user journeys before publishing, especially payments, permissions, and integrations.

Can I use my own domain?+

Yes. You can publish to a provided live address or connect your own custom domain. Domain registration is separate. The documentation walks you through setup.

Can I export my code?+

Yes. Solo and Agency include code export and GitHub sync, so you can work with your project outside the builder too.
